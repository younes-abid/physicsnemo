Training in Practice: Real Considerations
Consideration 1: Batch Composition
Should we mix timesteps or keep them separate?

Approach 1: Mixed batch (recommended)
Batch contains randomly sampled timesteps
[t1=15, t2=742, t3=100, t4=999, ...]

Pros: Network sees variety in each batch
Cons: GPU doesn't parallelize single-timestep ops

Approach 2: Stratified batch
Ensure equal representation of timesteps
[t1=50, t2=50, t3=50, t4=50, ...]

Pros: Balanced training
Cons: Requires careful batching
Most implementations use mixed batch!

The Two Types of Failure
Failure Mode 1: Slightly > 1
alpha_bar = -1e-12  # Due to rounding errors, we got NEGATIVE tiny number!
one_minus = 1 - (-1e-12) = 1.000000000001  # > 1
sqrt_one_minus = 1.0000000000005  # > 1, slightly wrong
Failure Mode 2: NaN (Catastrophic)
alpha_bar = 1.000000000001  # Due to rounding, > 1!
one_minus = 1 - 1.000000000001 = -1e-12  # NEGATIVE!
sqrt_one_minus = NaN  # BOOM! Program crashes
solution
# Bad (can overflow)
sqrt_one_minus_alpha_bar = torch.sqrt(1 - alpha_bar)

# Better (numerically stable)
sqrt_one_minus_alpha_bar = torch.sqrt(torch.clamp(1 - alpha_bar, min=1e-9))
Consideration 3: Learning Rate Scheduling
Training diffusion models benefits from:

Warmup: Start with tiny learning rate
Decay: Reduce learning rate over time
Cosine annealing: Nice for convergence
scheduler = CosineAnnealingLR(optimizer, T_max=num_epochs)
The "Restart" Variation
Sometimes we use Cosine Annealing with Warm Restarts (SGDR):

Learning Rate
    ^
1.0 |    /\        /\
    |   /  \      /  \
    |  /    \    /    \
    | /      \  /      \
    |/        \/        \
    +------------------------→

    Cycle 1  Cycle 2  Cycle 3
The learning rate:

Starts high
Decreases via cosine
Jumps back up ("restart")
Repeats
This helps escape local minima and can improve final performance!

Consideration 4: Exponential Moving Average (EMA)
In practice, we often keep two copies of the network:

Training network: Updated with gradients
EMA network: Exponential moving average of parameters
# Update EMA
for param_ema, param_train in zip(ema_model.parameters(), 
                                   train_model.parameters()):
    param_ema = 0.9999 * param_ema + 0.0001 * param_train
Use EMA network for sampling (more stable!)
